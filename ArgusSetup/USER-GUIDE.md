# ARGUS v1.0.0 — Інструкція користувача

**ARGUS** — нативна програма для Windows 10 і Windows 11 (x64) для моніторингу заліза в реальному часі, інвентаризації пристроїв, безпечного очищення системи, діагностики й оптимізації накопичувачів та клонування живої Windows (`CopyOS`).

Програма зібрана автономно на `.NET 10 LTS` та `Avalonia UI / Skia`: вона не потребує встановлення `.NET`, не містить WebView2 і не використовує небезпечного драйвера `WinRing0.sys`.

## Системні вимоги

- **ОС:** Windows 10 (версія 2004 / 22H2 і новіші, x64) або Windows 11 (x64).
- **Права доступу:** права адміністратора (UAC) потрібні для створення контрольних точок System Restore, оптимізації дисків (TRIM / дефрагментація) та клонування ОС (`CopyOS`). Інсталятор і `Argus.exe` запитують підвищення прав автоматично.
- **Місце на диску:** близько 60 МБ.

## Встановлення на іншому ПК

1. Скопіюйте теку `ArgusSetup` (або сам файл `Argus-Setup-1.0.0-win-x64.exe`) на цільовий ПК.
2. За бажанням перевірте цілісність файлу в PowerShell перед запуском:
   ```powershell
   Get-FileHash .\Argus-Setup-1.0.0-win-x64.exe -Algorithm SHA256
   ```
   Порівняйте хеш із рядком у файлі `SHA256SUMS.txt`.
3. Запустіть `Argus-Setup-1.0.0-win-x64.exe`.
   - **Примітка про SmartScreen:** локальна релізна збірка поки що не підписана комерційним сертифікатом Authenticode. Якщо Windows SmartScreen покаже попередження «Windows захистив ваш ПК», натисніть **«Детальніше»** -> **«Все одно виконати»**.
4. Виберіть мову майстра (українська або англійська), шлях встановлення (`C:\Program Files\Argus`), ярлик на Робочому столі та за потреби автозапуск у системний трей (`--minimized`).
5. Натисніть **«Завершити»** — ARGUS відкриється одразу.

### Портативний запуск без встановлення

Якщо встановлювати програму не потрібно, розпакуйте `Argus-Portable-1.0.0-win-x64.zip` у будь-яку теку й запустіть `Argus.exe`. Налаштування, правила очищення та журнали зберігаються в `%LOCALAPPDATA%\Argus`.

## Розділи програми

1. **Огляд** — зведені кругові датчики (CPU, ОЗП, GPU, системний диск), архітектура ПК, швидкий аналіз очищення та список підключених накопичувачів.
2. **Моніторинг** — жива телеметрія, закріплені шкали й графік Skia з фільтрацією серій (`CPU %`, `ОЗП %`, `GPU %`, `Темп. °C`, `Усі`), перемикачем часового вікна (`30 с` – `5 хв`), пороговими сповіщеннями та експортом звітів у HTML, JSON і CSV.
3. **Пристрої** — характеристики процесора, слотів ОЗП (SMBIOS), материнської плати, BIOS/UEFI, відеокарт і мережевих адаптерів, а також живе дерево пристроїв Windows із пошуком і фільтрами за шинами.
4. **Очищення** — двокрокове очищення за зовнішніми JSON-правилами (спершу аналіз, потім видалення), білий список винятків, автоматичний пропуск символічних посилань (`ReparsePoint`) і контрольна точка System Restore.
5. **Диски** — розпізнавання HDD / SATA SSD / NVMe, показники S.M.A.R.T., безпечна оптимізація (для SSD/NVMe — лише TRIM без дефрагментації, для HDD — дефрагментація) та карта найбільших тек на кожному томі.
6. **Міграція ОС (`CopyOS`)** — клонування живої Windows на внутрішній диск (SATA / NVMe / RAID) або зовнішній USB-носій у режимах `BLOCK (VSS Bitmap)` або `VSS + DISM` (GPT/UEFI або MBR/Legacy) із перевіркою плану, подвійним підтвердженням вибору диска та гарантованим прибиранням VSS-знімка.
7. **Журнал записів** — хронологічний аудит операцій програми.
8. **Налаштування** — інтервал опитування датчиків, пороги сповіщень, поведінка трею, автозапуск, контрольна точка System Restore й опційний режим розширених сенсорів PawnIO.

## Видалення

Відкрийте **Налаштування Windows -> Програми -> Встановлені програми**, знайдіть **ARGUS** і натисніть **«Видалити»** (або запустіть деінсталятор із меню «Пуск»).

## Цифровий підпис для публічного релізу

Для поширення серед широкого кола користувачів без попереджень SmartScreen підписуйте `Argus.exe` і `Argus-Setup-1.0.0-win-x64.exe` за допомогою сертифіката Authenticode або **Microsoft Trusted Signing**:

```powershell
.\scripts\Build-Release.ps1 -SignCertThumbprint "<THUMBPRINT>"
```
