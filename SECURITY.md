# Security Policy

## Supported Versions

Only the latest release of **ARGUS** (Windows 10 / 11 x64) receives security updates and bug fixes.

## Reporting a Vulnerability

If you discover a security vulnerability in ARGUS (including privilege escalation, unsafe file deletion, or updater integrity issues), please report it responsibly via GitHub Security Advisories on `https://github.com/PIFAG0R0302/ARGUS/security/advisories/new` or by opening a private report to the repository maintainer (`PIFAG0R0302`).

Please include:
- Affected ARGUS version and Windows build;
- Steps to reproduce or proof-of-concept;
- Potential impact.

Confirmed issues will be acknowledged and patched in the next release.
