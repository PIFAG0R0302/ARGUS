2. СЕРВІС ОНОВЛЕНЬ З GITHUB RELEASES (`GitHubAppUpdateService`)
---------------------------------------------------------------
- У `Argus.Core` (`SystemShellContracts.cs`, `ArgusSettings.cs`) додано контракти `IAppUpdateService`, `AppUpdateCheckResult`, `AppUpdateDownloadResult`, подію `UpdateAvailableEvent` і параметри `CheckUpdatesOnStartup`, `GitHubUpdateRepository` (`PIFAG0R0302/ARGUS`) та `TrustedSignerThumbprint`.
- У `Argus.Maintenance` (`GitHubAppUpdateService.cs`) реалізовано:
  * Запит останнього релізу через `https://api.github.com/repos/PIFAG0R0302/ARGUS/releases/latest`.
  * Потокове завантаження нового інсталятора з індикацією прогресу 0–100 %.
  * Обов'язкову звірку контрольної суми SHA-256 із файлом `SHA256SUMS.txt` релізу.
  * Нативну перевірку вбудованого цифрового підпису Authenticode через Win32 CryptoAPI (`crypt32.dll`: `CryptQueryObject`, `CertGetCertificateContextProperty`) і звірку відбитка сертифіката з `TrustedSignerThumbprint` (при невідповідності файл автоматично видаляється, а запуск блокується).
- У `SettingsView.axaml` / `SettingsViewModel.cs` додано блок «Оновлення з GitHub» із кнопкою «Перевірити оновлення», перемикачем тихої перевірки під час старту, карткою знайденого оновлення, діалогом підтвердження «Ви точно хочете завантажити оновлення з GitHub і запустити інсталятор?» та шкалою завантаження.
- У `MainWindow.axaml` / `MainWindowViewModel.cs` додано індикатор доступного оновлення у верхній панелі вікна для швидкого переходу до встановлення.
