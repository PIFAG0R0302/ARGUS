# ARGUS — Масштабне UX-оновлення та реструктуризація інтерфейсу

Цей документ об'єднує всі вимоги щодо спрощення, групування та інтерактивності інтерфейсу ARGUS по 7 вкладках.

---

## 1. Моніторинг (`MonitoringView.axaml` / `MonitoringViewModel.cs`)
- **Видалити секції:**
  - Повністю прибрати блоки **«Накопичувачі»** та **«Додаткові сенсори»**.
  - Прибрати напис **«Рівень 1: базові API увімкнено, але драйвер не встановлено»**.
- **Згортання/розгортання (Expander / Toggle):**
  - **«Завантаження по потоках CPU»** — зробити інтерактивним блоком, який можна згорнути або розгорнути на окремі потоки.
  - **Відеоадаптер (GPU / NVIDIA GeForce)** — зробити так само згортаним/розгортаним.
- **Інтерактивні кругові діаграми (CPU, RAM, GPU, Температура):**
  - Зробити самі кругові діаграми клікабельними.
  - При натисканні на будь-яку з них унизу розгортається компактна панель/віконечко зі списком топ-споживачів цього ресурсу (які процеси найбільше навантажують CPU, RAM, GPU або впливають на температуру). Повторний клік згортає панель.

---

## 2. Мережа (`NetworkView.axaml` / `NetworkViewModel.cs`)
- **Спрощення панелі керування (прибрати зайве):**
  - Прибрати кнопки/перемикачі вкладок **«Трафік по процесах»** та **«Правила фаєрволу»**.
  - Прибрати поле пошуку («Пошук за процесом, PID, IP-адресою...»).
  - Прибрати фільтри **«Усі»**, **«ESTABLISHED»**, **«LISTENING»**, **«TCP»**, **«UDP»**.
  - **Залишити лише** кнопку/перемикач **«Лише підозрілі»**.
- **Групування мережевих процесів із викидним списком (Expander):**
  - Якщо одна програма відкриває кілька мережевих з'єднань/процесів (наприклад, `antigravity`, `ChatGPT`, `Google Chrome`, `Google Drive`), не показувати їх окремими дублями.
  - Відображати **один зведений рядок на програму** (назва, кількість з'єднань, індикатор підозрілості).
  - При натисканні на програму розгортається підсписок усіх її окремих мережевих процесів/з'єднань (PID, порти, Remote IP, стан, дії блокування).

---

## 3. Процеси (`ProcessesView.axaml` / `ProcessesViewModel.cs`)
- **Прибрати пошук:** видалити поле пошуку процесу за назвою.
- **Групування з викидним списком (Expander):**
  - Аналогічно до вкладки «Мережа»: одна програма = один зведений рядок, при кліку розгортається підсписок усіх її процесів/інстансів.

---

## 4. Пристрої (`DevicesView.axaml` / `DevicesViewModel.cs`)
- **Прибрати зайве:**
  - Видалити поле пошуку пристрою за назвою.
  - Прибрати технічний напис **«Монітор CFG MGR 32»**.
- **Групування з викидним списком (Expander):**
  - Якщо один пристрій (наприклад, клавіатура) має кілька записів — згрупувати в один рядок, а при кліку розгортати підсписок.

---

## 5. Диски (`DisksView.axaml` / `DisksViewModel.cs`)
- **Інтерактивна карта/список найбільших тек на томі (drill-down):**
  - При кліку на папку (наприклад, `Games`) залишається обрана папка й відкривається її вміст (підпапки/файли).
  - Додати можливість вибирати елементи всередині та видаляти їх прямо звідси (з підтвердженням видалення та кнопкою повернення назад / на рівень вище).

---

## 6. Очищення (`CleanupView.axaml` / `CleanupViewModel.cs`)
- **Прибрати блоки:** видалити віконечка **«Білий список винятків»** та **«Запобіжники очищення»**.

---

## 7. Автозапуск і Служби (`StartupAndServicesView.axaml` / `StartupAndServicesViewModel.cs`)
- **Прибрати пошук:** видалити поле пошуку («Пошук за назвою програми, командою служби або шляхом...»).
- **Залишити перемикання:** «Автозапуск» / «Служби Windows».
- **Додати фільтрацію та сортування (щоб не було суцільного списку):**
  - Швидкі фільтри-пігулки над списком:
    - Для автозапуску: за джерелом (`Усі`, `Registry`, `Startup`, `Task Scheduler`) та/або за станом (`Увімкнено`, `Вимкнено`).
    - Для служб: за станом (`Усі`, `Працює`, `Зупинено`) та типом запуску (`Автоматично`, `Вручну`, `Вимкнено`).
  - Стабільне сортування (клікабельні заголовки стовпців або перемикач): за назвою, станом, типом запуску.

---

## 8. Налаштування та Масштабування (`SettingsView.axaml` / `MainWindow.axaml`)
- Додати налаштування **масштабування інтерфейсу** (загальний UI scale, наприклад 80%–150%, через `LayoutTransformControl` зі збереженням у конфіг).
- Підтримати динамічну зміну масштабу гарячими клавішами, як у браузері: `Ctrl + '+'` / `Ctrl + '-'` / `Ctrl + 0` (скидання) та `Ctrl + коліщатко мишки`.
