# ARGUS v1.2.0 — Опис оновлення

Версія **1.2.0** (Windows 10 / 11 x64) оновлює інтерфейс 7 розділів програми, додає інтерактивну роботу з папками на дисках та глобальне масштабування інтерфейсу.

## Що нового

### 1. Моніторинг
- Прибрано зайві блоки «Накопичувачі», «Додаткові сенсори» та банер про рівень API.
- Секції «Завантаження по потоках CPU» та картку «Відеоадаптер» тепер можна згортати й розгортати.
- Кругові шкали **CPU**, **RAM**, **GPU** та **Температура** стали клікабельними: натискання відкриває компактну панель топ-споживачів ресурсу, повторний клік її згортає.
- Для **GPU** додано читання навантаження по PID через лічильники продуктивності `GPU Engine` (із запасним ранжуванням за CPU/RAM, якщо лічильники недоступні).

### 2. Мережа
- Панель керування спрощено: прибрано вкладки «Трафік по процесах» і «Правила фаєрволу», поле пошуку та фільтри стану й протоколу, залишено перемикач **«Лише підозрілі»**.
- З’єднання згруповано по програмах: замість повторюваних рядків показується один зведений рядок із лічильником з’єднань, сумарним бейджем підозрілості та кнопкою блокування.
- За замовчуванням групи згорнуті; у режимі «Лише підозрілі» групи розгортаються автоматично.

### 3. Процеси
- Прибрано поле пошуку.
- Багатопроцесні програми згруповано в один зведений рядок (сумарні CPU %, RAM, Disk I/O та кількість процесів) із можливістю розгорнути окремі PID для перегляду чи завершення.
- Сортування за заголовками стовпців і живі оновлення без стрибків списку.

### 4. Пристрої та Очищення
- У «Пристроях» прибрано поле пошуку та технічний напис `CfgMgr32`; повторювані інтерфейси одного пристрою згруповано у згорнуті за замовчуванням рядки.
- В «Очищенні» прибрано інтерфейсні картки «Білий список винятків» та «Запобіжники очищення» (усі захисні правила в рушії працюють далі).

### 5. Диски
- У карті найбільших тек додано перехід всередину папок (drill-down) із показом підпапок і файлів та кнопками навігації («На рівень вище», «До кореня тому»).
- Додано вибір елементів прапорцями та видалення у **Кошик Windows** із підтвердженням, пропуском символічних посилань (`ReparsePoint`) і блокуванням системних тек (`Windows`, `Program Files`, `ProgramData`, корені томів, папка `ARGUS`).

### 6. Автозапуск і Служби
- Прибрано поле пошуку.
- Додано швидкі фільтри-пігулки: для автозапуску — за джерелом (`Registry`, `Startup`, `Task Scheduler`) та станом; для служб — за станом (`Працює`, `Зупинено`) й типом запуску (`Автоматично`, `Вручну`, `Вимкнено`).
- Додано стабільне сортування за кліком на заголовки стовпців.

### 7. Масштабування інтерфейсу
- У Налаштуваннях додано вибір масштабу інтерфейсу від **80%** до **150%** (повзунок і швидкі кнопки) зі збереженням у `settings.json`.
- Працюють гарячі клавіші масштабування: `Ctrl + '+'`, `Ctrl + '-'`, `Ctrl + 0` (скидання) та `Ctrl + коліщатко миші`.
