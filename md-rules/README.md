# ARGUS — Стиснутий контекст чатів (`md-rules`)

Ця папка містить стислі файли стану та історії попередніх чатів проєкту ARGUS для економії токенів.
Новий чат може прочитати відповідний `.md`-файл замість перечитування довгої історії листування:

- `bugfix-rule.md` — історія та стан багфіксів, UX-оновлень і перевірок.
- `main-project-rule.md` — історія основної розробки, архітектури та релізів.
