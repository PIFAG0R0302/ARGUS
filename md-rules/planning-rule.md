# ARGUS — Правило планування та архітектури

Компактний підсумок рішень із сесії планування `ARGUS Planning` для нового чистого чату.

## 1. Концепція та UX-рішення

- **Мета:** перетворити ARGUS на цілеспрямовану портативну програму повного моніторингу та керування Windows 10/11 (заміна зв'язки HWiNFO + CrystalDiskInfo + BleachBit + базовий Sysinternals/Firewall без реклами, платних обмежень і вразливого драйвера `WinRing0.sys`).
- **Гібридний інтерфейс:** у базовому режимі показуємо чисту картину (головні метрики, програми користувача, прості дії). Перемикач **«Експертний режим»** працює **всередині вкладок** (не ховає пункти меню), відкриваючи системні процеси й служби, PID, локальні порти, розширені дії та атрибути.
- **Модель прав (UAC):** запуск без прав адміністратора (безпечний перегляд і моніторинг). Підвищення прав — на вимогу кнопкою перезапуску з UAC-підтвердженням для змін у системі. Обов'язковий захист критичних процесів і служб Windows.
- **Фоновий режим і трей:** опційний режим у системному треї (вимкнений за замовчуванням). Алерти лише щодо заліза та дисків: перегрів CPU/GPU, критично мало місця на диску, погіршення S.M.A.R.T.
- **Структура навігації:**
  - `Огляд` — головний дашборд і топ-навантаження.
  - `Моніторинг` — сенсори заліза в реальному часі.
  - `Система` (об'єднаний розділ із підвкладками): `Пристрої`, `Диски`, `Автозапуск`, `Служби`, `Очищення`, `Процеси`.
  - `Мережа` — активні з'єднання та керування правилами Windows Firewall.
  - `Міграція ОС` (CopyOS) — залишається в меню, розвиток заморожено.
  - `Журнал` — журнал подій і дій програми.
  - `Налаштування` — параметри трею, алертів, Експертного режиму та UAC.

## 2. Дорожня карта по фазах

### Фаза 1 — Пріоритетний функціонал (база реалізована в коді)
- **Створено в `src/Argus.App`:**
  - Режим UI та трей: `AppUiModeService.cs`, `WindowsTrayNotificationService.cs`.
  - `Мережа`: `NetworkView.axaml` / `NetworkViewModel.cs` (TCP/UDP-з'єднання, порти, процеси, правила Windows Firewall).
  - `Автозапуск і Служби`: `StartupAndServicesView.axaml` / `StartupAndServicesViewModel.cs` (перегляд і базове керування з захистом системних служб).
- **Перевірити та довести до фіналу (якщо ще не завершено):** фінальна інтеграція підвкладок у розділі `Система`, наскрізне тестування UAC-підвищення, ізоляція створених правил Firewall (префікс `ARGUS_`, щоб не чіпати системні й сторонні правила в базовому режимі).

### Фаза 2 — Поглиблення моніторингу
- **`Система` -> `Процеси`:** `ProcessesView.axaml` / `ProcessesViewModel.cs` та `GpuProcessMetricsReader.cs` уже додані в проєкт; далі — стабілізація, фільтрація системних процесів через Експертний режим і перевірка безпеки дій.
- **`Мережа` v2 (заплановано):** лічильник швидкості (КБ/с) і спожитого трафіку по кожному процесу через ETW-трасування.

### Фаза 3+ — Відкладені задачі (лише після стабілізації Фаз 1–2)
- Безпечне прибирання «мертвих» записів автозапуску в реєстрі (із попереднім `.reg`-бекапом) та інвентаризація/перевірка драйверів через Windows Update або `winget` (без сторонніх баз драйверів).

## 3. Свідомі анти-цілі (чого НЕ робимо)

- Власний антивірус або сканер малварі.
- Ігровий оверлей поверх DirectX/Vulkan (ніша MSI Afterburner / RTSS).
- Твікер/деблоатер Windows (телеметрія, контекстні меню тощо), окремий менеджер планів живлення, інтеграція Windows Defender та Event Log / BSOD.
- Повноцінне «очищення реєстру» та автозавантаження драйверів із зовнішніх сайтів.
- Активний розвиток модуля `Міграція ОС` (CopyOS) — тримаємо замороженим у робочому стані.

## 4. Ключові рішення для наступного чату

1. **Експертний режим не змінює дерево меню** — він керує деталізацією та видимістю системних/небезпечних елементів усередині кожної вкладки.
2. **Безпека понад усе:** жодних вразливих kernel-драйверів рівня `WinRing0.sys`, обов'язковий білий список захищених системних служб/процесів, правила Firewall ARGUS мають бути ідентифікованими та відкатними.
3. **Фокус без роздування:** кожну нову фічу перевіряти проти списку анти-цілей із розділу 3.
4. **Замороження CopyOS:** не витрачати ресурси на `Argus.Migration`, окрім критичних виправлень, якщо вони заважають збірці рішення.
